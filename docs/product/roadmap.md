# Product Roadmap

---

# Overview

The roadmap defines the planned evolution of Farmoria from the initial Minimum Viable Product (MVP) to a production-ready ecommerce platform.

The roadmap is divided into multiple releases, where each release introduces new customer value while improving the technical foundation of the application.

---

# Version 1.0 — Minimum Viable Product

## Objectives

Deliver a fully functional ecommerce platform with modern infrastructure.

### Product Features

- Homepage
- Product categories
- Product catalog
- Product pages
- Shopping cart
- Checkout
- Contact page
- Mobile responsiveness

### Technical Features

- Docker
- Kubernetes
- MariaDB
- Redis Object Cache
- Persistent Volumes
- GitHub Actions
- Documentation

---

# Version 1.1 — Customer Experience

## Objectives

Improve usability and increase customer engagement.

### Features

- Product reviews
- Wishlist
- Related products
- Newsletter
- Blog
- Improved homepage
- Better product filtering

---

# Version 2.0 — Growth

## Objectives

Expand business capabilities.

### Features

- Loyalty program
- Customer profiles
- Advanced search
- Product comparison
- Promotions
- Discount engine
- Better analytics

---

# Version 3.0 — Cloud Production

## Objectives

Prepare the platform for production deployment.

### Infrastructure

- AWS deployment
- HTTPS
- Domain configuration
- Backup automation
- Monitoring
- Logging
- Production security improvements

---

# Long-Term Vision

Future development may include:

- AI product recommendations
- Multi-language support
- Multi-currency
- Payment gateway integration
- Mobile application
- Inventory synchronization
- ERP integration

# Success Criteria

The roadmap will be considered successful when:

- Customers can complete purchases easily.
- The platform remains stable and scalable.
- New features can be delivered continuously.
- Infrastructure supports future cloud deployment.
- Product development follows clear priorities.
